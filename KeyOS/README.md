# KeyOS — Keypad Phone Operating System Simulator

An interactive, software-only keypad phone operating system simulator inspired by
classic feature phones. Runs entirely in the browser.

**All calls and messages in KeyOS are simulated. Nothing is sent over a real network.**

## Status

This project is built in twelve steps. **Step 1 is complete:**

- [x] Phone body, LCD screen and physical-style keypad
- [x] Live clock and date
- [x] Simulated signal strength and battery indicators
- [x] Keyboard + mouse input layer with press feedback
- [x] Screen navigation stack

## Technology

HTML5 · CSS3 · Vanilla JavaScript · LocalStorage · GitHub Pages

No backend, no build step, no external dependencies.
